## Tên và vòng đời

Dùng ADR-NNN-short-title.md, đánh số tăng dần khi có quyết định cần xem xét. Chưa tạo ADR cụ thể trong đợt khung. Trạng thái Draft → In Review → Approved; khi thay thế quyết định cần liên kết ADR mới và giữ lịch sử.
