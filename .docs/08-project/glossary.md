## Từ điển

| Thuật ngữ | Ý nghĩa |
|---|---|
| PRD | Tài liệu yêu cầu sản phẩm/module |
| ADR | Bản ghi quyết định kiến trúc |
| AC | Tiêu chí nghiệm thu |
| NFR | Yêu cầu phi chức năng |
| TBD | Chưa xác định; cần hoàn thiện trước việc phụ thuộc |
| Draft | Đang soạn, chưa duyệt |
| In Review | Đã gửi xem xét |
| Approved | Có người duyệt và bằng chứng cho phạm vi cụ thể |
| Preview | Bản chạy để review trước production |
| Rollback | Khôi phục phiên bản vận hành trước đó |

Thuật ngữ sản phẩm dùng [từ điển nghiệp vụ](../02-domain/terminology.md).
